# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in RPG AI Hub, please report it responsibly:
- Do NOT create a public GitHub issue.
- Send an email detailing the vulnerability, impact, and reproduction steps to the project maintainers.

## API Key Security Standards

- API keys must never be stored in plaintext.
- API keys must never be committed to repository branches.
- Debug outputs and logs must redact authorization headers and secrets.
